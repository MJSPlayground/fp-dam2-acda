# Referencia histórica de Ficheros

Estas páginas conservan el material anterior al rediseño del tema. Se han trasladado fuera de `docs/` para que Zensical no las publique ni las incluya en su buscador como contenido vigente.

El alcance actual lo define `CONTENIDOS_ACDA.md`. Este archivo histórico no sustituye ese índice ni constituye una entrega validada del nuevo itinerario.

Los enlaces relativos conservan el contexto original de `docs/ficheros/`; para reconstruir una versión anterior completa se puede consultar el historial Git. Los proyectos históricos siguen disponibles en `proyectos/ficheros/` como fuente de componentes reutilizables.
