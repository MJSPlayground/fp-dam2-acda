# Gestor comercial — proyecto inicial

Requiere JDK 25. Ejecuta `.\mvnw.cmd javafx:run` en Windows o `./mvnw javafx:run` en Linux/macOS. La interfaz abre las secciones Clientes, Productos y Operaciones; muestra formularios contextuales y permite navegar, buscar en la tabla y cancelar. Los botones de guardado, eliminación, importación y exportación informan que falta implementar la operación. El proyecto compila y se puede importar sin modificar archivos.

Completa la persistencia, las reglas comerciales, las conversiones y los informes del [enunciado](https://mjsplayground.github.io/fp-dam2-acda/ficheros/final-gestor/). Guarda datos modificables en una carpeta externa configurable. Los recursos empaquetados son de solo lectura. El proyecto inicial no incluye clases de la solución.
