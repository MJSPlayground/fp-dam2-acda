# Bases de datos documentales con Cloud Firestore

Cloud Firestore almacena documentos agrupados en colecciones. Este tema conectará la persistencia documental con servicios Spring Boot y una API REST que intercambie JSON.

## Recorrido

Comienza con **persistencia documental** y **configuración y acceso seguro**. Continúa con **modelado y persistencia**, **HTTP y REST**, **buenas prácticas de API** y **consultas y consistencia**. Al final habrá prácticas finales y **Ampliación**.

Consulta [Ayuda y herramientas](../ayuda/index.md) para la configuración general y el tratamiento de credenciales. Los bloques se publicarán progresivamente.

Continúa con [Bases de datos NoSQL con MongoDB](../mongodb/index.md).
