# Guía

Esta sección demuestra cómo organizar varias páginas y exportarlas en un mismo PDF.

## Introducción

Escribimos el contenido una vez en Markdown. Zensical produce la web y el generador convierte las páginas en un PDF con portada e índice.

!!! tip "Colores"
    Modifica `docs/stylesheets/colors.css` para aplicar tu paleta. El resto de componentes es común.

Continúa con [Organización](organizacion.md).
