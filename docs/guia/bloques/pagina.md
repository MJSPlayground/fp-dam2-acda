# Página dentro de un bloque

Esta página demuestra un **submenú colapsable** en la navegación izquierda.

## Ejemplo

!!! example "El mismo contenido en el PDF"
    Al descargar **Guía**, este apartado se incorpora al índice jerárquico y al contenido impreso.

El mismo sistema permite incorporar páginas de Físicas, Cámaras, Animaciones, capítulos de API u otros bloques especializados.
